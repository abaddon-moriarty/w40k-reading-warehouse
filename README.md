# w40k-reading-warehouse
Reading data warehouse: Warhammer 40k novels + KOReader stats → DuckDB → dbt.  
ELT pipeline, dimensional modeling, data quality. Learning project for modern data engineering practices.

A learning project combining K-Readers reading data with Warhammer 40k corpus to practice modern data engineering: ELT pipelines, dimensional modeling, DuckDB, dbt, and data quality tools.

Stack: Python (uv), DuckDB, dbt, pytest, sqlfluff
Corpus: 37 English Warhammer 40k novels (personal collection)
Data sources: K-Readers stats DB, wiki.gg corpus (CC BY-NC 4.0)
